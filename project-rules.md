# Правила проекта

## Технологии

### Использовать:
- HTML5
- CSS3

### Не использовать:
- React
- Vue
- Angular

## HTML

Использовать семантические HTML-теги.

## CSS

Не использовать inline-стили без необходимости.

## Дизайн

Сайт должен быть адаптивным.

## Код

Не переписывать существующий код без необходимости.

---

## Дополнительные рекомендации

### Структура HTML:
- Использовать `<header>`, `<main>`, `<footer>`, `<nav>`, `<section>`, `<article>` и другие семантические теги
- Теги `<div>` использовать только для группировки без семантического значения

### CSS:
- Стили хранить в отдельном файле (style.css)
- Использовать медиа-запросы для адаптивности
- Применять BEM или другую методологию именования классов при необходимости

### Адаптивность:
- Проверять на разных размерах экранов
- Использовать относительные единицы (%, rem, em)
- Применять flexbox или grid для верстки

### Код:
- Поддерживать существующую структуру проекта
- Комментировать сложные участки кода
- Следить за читаемостью и поддерживаемостью кода
